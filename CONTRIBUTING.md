# Contribuir

Obrigado por querer contribuir com o Pulso 3.5.

## Antes de abrir um pull request

1. Abra uma issue para discutir mudanças maiores ou suporte a um novo modelo de tela.
2. Mantenha o escopo claro e descreva o comportamento observado e o esperado.
3. Para mudanças no painel, no editor ou na comunicação, explique como validou o resultado. Não use `--probe` sem uma tela compatível conectada.
4. Compile no Windows com `.\Compilar.ps1` e confira se o workflow de CI passa.
5. Atualize `README.md` quando mudar instalação, uso, compatibilidade ou distribuição.

## Pull requests

- Prefira alterações pequenas e com uma finalidade.
- Não inclua executáveis, logs, preferências ou dados pessoais do seu computador.
- Preserve a licença GPL-3.0-or-later nos arquivos derivados deste projeto e mantenha as atribuições de terceiros.
- Não inclua chaves, tokens, URLs privadas ou dados de clima de um usuário.

## Compatibilidade com telas

Informe marca/modelo, VID/PID, resolução, orientação e revisão de hardware. Separe claramente o que foi medido numa tela física do que foi apenas compilado ou validado em código.
