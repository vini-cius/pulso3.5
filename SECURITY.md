# Segurança

Use uma versão atual do Pulso 3.5 e baixe instaladores somente da página **Releases** do repositório oficial.

Para relatar uma vulnerabilidade, use **Security → Report a vulnerability** no GitHub quando o relatório privado estiver habilitado. Não publique detalhes exploráveis em uma issue aberta. Inclua a versão afetada, os passos para reproduzir e o impacto observado.

O atualizador aceita apenas manifesto e pacote HTTPS, limita o tamanho do download, verifica o SHA-256 do pacote e restringe os arquivos que pode substituir. O hash detecta corrupção do pacote; a origem e a publicação do manifesto continuam confiadas ao endereço HTTPS configurado pelo usuário.
